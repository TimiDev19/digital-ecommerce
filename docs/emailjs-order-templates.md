# StephGifts order email templates in EmailJS

The site sends emails only after the Paystack webhook verifies a successful payment. It uses two EmailJS templates so the business and customer can receive different versions of the order summary.

## Before creating templates

1. In EmailJS, connect the email service that StephGifts will send from.
2. Create two email templates: **StephGifts — Business Order Summary** and **StephGifts — Customer Receipt**.
3. Use the field values below for each template. EmailJS template variables are case-sensitive.
4. Copy both template IDs, the service ID, and the account API keys into `.env.local` and your Netlify environment variables. Use the matching names in `.env.example`.

## Template 1: Business order summary

- **To Email:** `{{to_email}}`
- **Subject:** `{{subject}}`
- **Content (HTML):**

```html
{{{html_content}}}
```

This message is addressed to `oduneyestephen04@gmail.com` by default (or `ORDER_NOTIFICATION_EMAIL`). It includes the registered customer email, order reference, products, quantities, selected options, paid total, and gift delivery details when applicable.

## Template 2: Customer order receipt

- **To Email:** `{{to_email}}`
- **Subject:** `{{subject}}`
- **Content (HTML):**

```html
{{{html_content}}}
```

The recipient is read from the customer's signed-in Supabase account when the payment webhook verifies the payment. The receipt includes the order reference, purchased products, quantities, options, paid total, and gift delivery details when applicable.

The HTML is generated by the server and escapes customer-entered values before placing them in the template. Do not replace the triple-brace HTML variable with user-submitted content.

## Environment variables

- `EMAILJS_SERVICE_ID`: connected EmailJS email service ID.
- `EMAILJS_MERCHANT_TEMPLATE_ID`: business order summary template ID.
- `EMAILJS_CUSTOMER_TEMPLATE_ID`: customer receipt template ID.
- `EMAILJS_PUBLIC_KEY`: EmailJS public key.
- `EMAILJS_PRIVATE_KEY`: EmailJS private key; server-side only.
- `ORDER_NOTIFICATION_EMAIL`: business inbox; defaults to `oduneyestephen04@gmail.com`.

EmailJS limits the send endpoint to one request per second. The webhook spaces the two template sends accordingly.
