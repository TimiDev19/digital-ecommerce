# StephGifts

A considered digital goods storefront built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, Redux Toolkit, Supabase and Paystack.

## Run locally

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env.local` and fill in the values described in that file. The Supabase project URL and keys are in **Supabase Dashboard → Project Settings → API**. The Paystack secret is in **Paystack Dashboard → Settings → API Keys & Webhooks**. Generate `ADMIN_SESSION_SECRET` with `openssl rand -base64 32`.
3. Apply the SQL migrations in `supabase/migrations/` in filename order, using the Supabase SQL Editor or Supabase CLI. This includes the `product-images` public storage bucket migration used for uploaded catalog cover images.
4. The migrations create the `digital-products` bucket for any existing purchased downloads and the public `product-images` bucket for catalog cover images. Product cover images are uploaded in the admin panel.
5. For transactional order emails, connect an email service in EmailJS (Gmail can be used for low volume), create a template using `{{to_email}}` for the recipient, `{{subject}}` for the subject, and `{{{html_content}}}` for the HTML body, then set `EMAILJS_SERVICE_ID`, `EMAILJS_TEMPLATE_ID`, `EMAILJS_PUBLIC_KEY`, and `EMAILJS_PRIVATE_KEY`. `ORDER_NOTIFICATION_EMAIL` defaults to `oduneyestephen04@gmail.com`. Apply the order email notification migration before enabling email delivery.
6. For payments, configure the Paystack webhook URL as `https://YOUR_DOMAIN/api/paystack/webhook` and use a Paystack test secret during development.
7. Start the app with `npm run dev`, then visit `/admin/login` to manage the catalog.

The admin login is hard-coded in `src/lib/admin-auth.ts`; the current credentials are `admin@steph.com` and `Password123!`. Change them there before deployment. Admin sign-in also requires the private `ADMIN_SESSION_SECRET` environment variable.

Never put the Supabase service role key or Paystack secret in a `NEXT_PUBLIC_` variable.

## Included

- Editorial home, catalog filtering/search/sorting, product pages and a mobile-first responsive design.
- Redux cart with guest browser persistence, account cart sync and guest-to-account merge.
- Supabase email/password signup, sign-in, password reset, private library, admin analytics and RLS policies.
- Server price lookup, Paystack initialization, signature-checked and transaction-verified webhook fulfillment, merchant/customer order emails tracked for webhook retries, private signed downloads, download history.
- Supabase schema, empty starting catalog, SEO metadata, sitemap and robots rules.

The shop starts without seeded products so StephGifts can add its actual catalog through the admin panel. Product IDs are generated by the database; each active product needs a price, and all products are featured in the shop by default. Product descriptions are optional. Supabase and Paystack credentials are required before enabling live payments.
